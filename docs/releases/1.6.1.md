# Judais-Lobi 1.6.1

Portable checkpoint validation.

26 September 2026. Publication and deployment are separate from this source record.

This patch adds read-only native checkpoint capture and validation for callers
that need to preserve a complete conversation's referenced run material.

- Validate exact part identities and hashes without replaying tools or models.
- Refuse incomplete, changed, oversized or unsupported checkpoint closures.
- Respect native run locks and refuse a capture racing active work.
- Expose a bounded private-process request/response wire with no partial-success
  output. The caller retains responsibility for current authorization, export
  policy and excluding concurrent transcript changes.
- Keep the existing runtime event contract and ordinary Mission behavior.

This is **not** automatic backup, cross-host resume, offline synchronization or
conflict reconciliation. Those require integration and independent acceptance
by the consuming platform. No new network service is started.

See [portable checkpoints](../portable-checkpoints.md) for the contract and
[verification](../portable-checkpoint-verification.md) for the source tests,
fault checks and synthetic integration evidence.
